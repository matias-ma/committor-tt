# Historical notebook

`legacy_quickstart.ipynb` uses the original discrete TT implementation. It is
retained as a research reference, not as an example of the current API. To run
it, use [the original revision](https://github.com/matias-ma/committor-tt/tree/2def659d2e39c98bc2211afa8f23d1e37befd62c).

For the current implementation, use the quick start in the root README and
the scripts in `examples/`. The PNG files here are retained research figures.
